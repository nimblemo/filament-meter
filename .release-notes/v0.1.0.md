## v0.1.0 — First public release

The first release of **`filament-meter`**, a focused CLI that answers one
question: *given a path to a model (or a whole folder of models), how much
filament will it consume?* It reads the numbers slicers already write into
sliced files, and — when a model has not been sliced yet — provisions
OrcaSlicer automatically to do it for you.

---

### What is `filament-meter`?

`filament-meter` walks a file, a directory or a glob pattern, and for each
`.3mf` / `.gcode` / `.stl` / `.obj` it reports filament usage in grams and
metres, estimated print time, and (optionally) cost. The data comes from
`Metadata/slice_info.config` inside sliced files, with a G-code footer
fallback. Sliced files are parsed locally and instantly; anything else is
sliced on demand.

---

### Highlights

- **One flat command** — `filament-meter PATH`. No subcommands, just flags.
- **Fast path first** — already-sliced files never launch OrcaSlicer.
- **Automatic OrcaSlicer provisioning** — a portable build is downloaded
  lazily into the user cache on first slice, or eagerly with
  `--install-orca`. No admin rights, no `pip install`-time downloads.
- **Never pollutes your models** — slicing happens in a temporary directory
  (or `--keep-sliced DIR`); no large files land next to your sources.
- **Proven slicing workarounds** — `--allow-newer-file` plus the adaptive
  `--<key>=<min>` retry for `not in range` errors, both verified on real
  Bambu Studio exports.
- **Four formats** — human table, JSON, CSV (`;`-separated, Excel-friendly)
  and Markdown.
- **Pure stdlib + `uv`** — the only runtime dependency is `platformdirs`.

### Installation

```bash
# Recommended (one-shot, isolated)
uv tool install filament-meter
filament-meter --help
```

Requires [uv](https://docs.astral.sh/uv/getting-started/installation/).
Substitute `pipx` or `pip` if you prefer.

For development, run from a local checkout:

```bash
git clone https://github.com/nimblemo/filament-meter.git
cd filament-meter
uv sync --all-extras
uv run filament-meter "D:/models/Gesha_sliced.3mf"
```

---

### Requirements

- **Python ≥ 3.11** (CI matrix: 3.11 / 3.12 / 3.13)
- **OrcaSlicer** — optional; downloaded automatically when a model needs
  slicing.
- Outbound HTTPS to `api.github.com` / `github.com` only when OrcaSlicer
  must be downloaded.

---

### Usage at a glance

```bash
filament-meter "D:/models/Gesha_sliced.3mf"          # one file, instant
filament-meter "D:/models" --price 2200              # a folder + cost
filament-meter "D:/projects" --price 2200            # unsliced: auto-slice
filament-meter "D:/models" --price 2200 -o out.csv   # write a report
filament-meter --check                               # diagnostics
filament-meter --install-orca                        # fetch OrcaSlicer
```

Exit codes: `0` success · `1` partial · `2` usage/environment · `3` total
failure.
