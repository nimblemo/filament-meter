## v0.3.0 — Agent skill for installation & commands

A documentation/developer-experience release. The repository now ships an
[Agent Skills](https://agentskills.io/specification.md)-compliant skill that
teaches an AI agent how to install and operate `filament-meter` — the
installation order and the full CLI command reference.

---

### What's new

- **`skills/filament-meter/`** — an agent skill (installs to `.agents/skills/`)
  with:
  - `SKILL.md` — the installation order (Python ≥ 3.11 → `uv` → install
    method → OrcaSlicer auto-provisioning → verify) plus a command summary,
    usage examples and key facts.
  - `references/commands.md` — the full flag-by-flag table, exit codes,
    output formats, environment variables and persistent-state layout.

No runtime code changed; the Python package behaviour is identical to v0.2.1.

---

### Installation

```bash
uv tool update filament-meter        # 0.2.1 -> 0.3.0
```
