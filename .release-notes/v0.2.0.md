## v0.2.0 — Result cache, persistent settings, quieter OrcaSlicer

A performance and ergonomics release. `filament-meter` now remembers what it
has already measured, remembers your price and currency, and stops OrcaSlicer
from spraying its own output into your terminal.

---

### What's new

**A persistent result cache** — every model's filament figures are cached on
disk keyed by its **absolute path and file size**. Run the same folder twice
and the second run is effectively instant: unchanged models are never
re-sliced or re-parsed, and an edited or re-exported model (different size)
is automatically re-processed. Cost is never cached, so a change of
`--price` is always reflected.

```bash
filament-meter "D:/models" --jobs 4     # first run: slices
filament-meter "D:/models" --jobs 4     # second run: served from cache
filament-meter "D:/models" --no-cache   # opt out entirely
```

**Persistent settings** — `--currency` and `--price` are remembered. Pass
them once and they become the defaults on every later run:

```bash
filament-meter "D:/models" --price 2200 --currency RUB   # saved
filament-meter "D:/models"                                # uses 2200 RUB
```

**A quieter slicer** — OrcaSlicer's own console output (including the
Windows console window) is suppressed during slicing and version probing, so
only `filament-meter` output reaches your terminal.

---

### Where files live

- Result cache: `<cache-dir>/results/results.json` (relocate with
  `--cache-dir`, disable with `--no-cache`).
- Settings: `<config-dir>/settings.json` (relocate with the
  `FILAMENT_METER_CONFIG_DIR` environment variable).

Both follow the same platform conventions as the OrcaSlicer cache
(Windows `%LOCALAPPDATA%`, macOS `~/Library/…`, Linux `~/.config/…` /
`~/.cache/…`).

### Installation

```bash
uv tool install filament-meter        # or upgrade: uv tool upgrade filament-meter
filament-meter --version
```
