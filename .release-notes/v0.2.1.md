## v0.2.1 — Quiet OrcaSlicer (for real this time)

A small patch that silences OrcaSlicer once and for all. On Windows,
OrcaSlicer's executable is a GUI application: probing it with `--version`
dumped the full usage/help text straight into your terminal on every run.
`filament-meter` no longer probes the binary at all — it reads the `VERSION`
marker file instead — so only `filament-meter` output reaches your console.

---

### Fixed

- Removed the OrcaSlicer `--version` probe, which printed the entire usage
  dump (plus `setup params error`) to the parent console on Windows. The
  version is now read from the `VERSION` file written next to provisioned
  builds; a system install reports `unknown`.

---

### Installation

```bash
uv tool update filament-meter        # 0.2.0 → 0.2.1
filament-meter --version
```
